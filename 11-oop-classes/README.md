# 11 · OOP / Classes

## Что изучено
- `class` и объект (чертёж и изделие по нему)
- `constructor`, `this`, `new`
- методы: «изменялки» (меняют `this`) и «сообщалки» (возвращают через `return`)
- состояние объекта (объект помнит данные между вызовами)
- `getter` / `setter` — защита данных
- `extends` / `super` — наследование
- `static` — члены класса

## Что должен уметь
- грамотно писать классы и пользоваться конструктором
- создавать объекты через `new`
- использовать наследование (`extends`/`super`), чтобы не повторять один и тот же код в похожих классах
- защищать данные через `getter`/`setter` — отклонять невалидные значения
- понимать масштабируемость: добавил поле в родителя — оно есть у всех потомков
- объяснять, где `static`, где instance, и почему

## Сложные моменты
- `getter` срабатывает при чтении (`obj.x`), `setter` — при записи (`obj.x = ...`); оба без скобок
- поле-хранилище (`_x`) должно отличаться от имени `getter`/`setter`, иначе бесконечная рекурсия
- `super(...)` вызывается первым, до `this` (в потомке `this` недоступен, пока не отработал родитель)
- ненайденный у потомка метод ищется вверх по цепочке у родителя
- `static`-член живёт на классе (`Product.count`), instance — на объекте (`obj.name`)
