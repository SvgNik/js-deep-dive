# 04 · Loops and Strings

## Что изучено
- `for` — счётчик, направление, итерация по строке
- `while` — цикл без заранее известного числа итераций
- `do...while` — выполняется хотя бы один раз
- `break` — полная остановка цикла
- `continue` — пропуск текущей итерации
- Методы строк: `trim`, `toLowerCase`, `toUpperCase`, `includes`, `indexOf`, `slice`, `substring`, `split`

## Что должен уметь
- Написать `for` в любом направлении с любым шагом
- Использовать `while` когда количество итераций неизвестно
- Остановить или пропустить итерацию через `break` / `continue`
- Использовать паттерн аккумулятора внутри цикла
- Применять методы строк для поиска, обрезки и трансформации

## Файлы
- `01-count-loop.js` — базовый `for`, направления, шаг
- `02-break-continue.js` — `continue` для пропуска, `break` с аккумулятором
- `03-string-methods.js` — методы строк
- `04-final.js` — циклы + методы строк вместе

## Сложные моменты
- Паттерн аккумулятора: переменная объявляется до цикла, накапливает результат внутри
- `if` без фигурных скобок — опасная привычка, всегда использовать скобки
- `slice(start, end)` — `end` не включается, последний нужный индекс + 1

## Notes
- Строки неизменяемые — все методы возвращают новую строку
- `includes` — есть ли подстрока, `indexOf` — где именно
- Паттерн аккумулятора встретится снова в `reduce` (JS 09)
