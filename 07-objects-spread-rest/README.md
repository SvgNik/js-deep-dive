# 07 · Objects, spread/rest

## Что изучено
- Создание объектов, dot/bracket access
- Добавление, изменение, удаление свойств
- Методы объекта без `this`
- `for...in`
- `Object.keys`, `Object.values`, `Object.entries`
- Массивы объектов
- Spread для массивов и объектов
- Rest в параметрах функции

## Что должен уметь
- Создать объект и обращаться к его свойствам двумя способами
- Изменять, добавлять и удалять свойства
- Написать метод объекта без `this`
- Перебрать объект через `for...in`
- Получить ключи, значения и пары через `Object.keys/values/entries`
- Работать с массивом объектов
- Копировать и сливать объекты через spread
- Собирать аргументы функции через rest

## Сложные моменты
- - Паттерн аккумулятора в массиве объектов — как достать свойство
  из объекта внутри цикла (`product.grade` вместо просто `grade`)
- Разница между `products` и `product` внутри цикла — опечатка
  которая даёт `NaN`
- Spread как аргумент vs spread при создании объекта —
  `Object.keys(...products[0])` vs `Object.keys(products[0])`
- `return` внутри цикла останавливает функцию — нужен только после

## Notes
- `const` не защищает объект от мутации — только переменную от переприсвоения
- `for...in` итерирует все свойства включая методы
- Spread создаёт новый объект, `const b = a` — только ссылку
- При конфликте ключей в spread побеждает правый
