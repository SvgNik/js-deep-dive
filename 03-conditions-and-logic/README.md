md# 03 · Условия и логика

## Что изучено
- if / else if / else
- Тернарный оператор
- switch и fallthrough
- Логические операторы: &&, ||, !
- Truthy / falsy значения
- Short-circuit evaluation

## Что должен уметь
- Писать условия с несколькими ветками
- Использовать тернарный оператор для присвоения значений
- Использовать switch для проверки одной переменной на несколько значений
- Комбинировать && и || с правильными скобками
- Объяснить, какие значения falsy в JS
- Понимать, как short-circuit влияет на выполнение кода

- 02-discount.js — скидка по сумме заказа

## Сложные моменты
- Приоритет операторов: && выполняется раньше ||, скобки меняют порядок
- Без скобок isLoggedIn && A || B && C читается как (isLoggedIn && A) || (B && C)

## Notes
- isActive === true избыточно — достаточно просто isActive
- После блоков if/else точка с запятой не нужна
- Тернарный оператор только для простых присвоений, не для сложной логики
