# 10 · this и prototypes basics

## Что изучено
- `this` — что это и зачем нужно
- Правило `this`: зависит от того, КАК вызвали (что слева от точки), а не где функция написана
- `this` в методе объекта, в обычной функции и в arrow function
- Потеря `this` (метод оторвали от объекта → вызвали без объекта слева)
- `call`, `apply`, `bind`
- Prototypes как ссылка на «запасной» объект
- Prototype chain — поиск свойства по цепочке
- `Object.create` — создание объекта с заданным прототипом

## Что должен уметь
- Определять `this` по строке вызова (что слева от точки)
- Помнить, что у arrow function нет своего `this` — она берёт его из окружающего (lexical) контекста
- Воспроизводить и чинить потерю `this`
- `call` / `apply` — вызывают функцию сразу с указанным `this` (call — аргументы через запятую, apply — массивом), возвращают результат
- `bind` — НЕ вызывает, а возвращает новую функцию с намертво вшитым `this`
- Связывать объект с прототипом через `Object.create` и понимать, как идёт поиск по цепочке

## Сложные моменты
- Главный затык — понять саму концепцию `this`: что это не «зашито в функцию», а решается в момент вызова
- Происхождение функции неважно — где функцию объявили или откуда скопировали, на `this` не влияет (пример dog/cat)
- Разница `obj.method()` и `obj.method`: со скобками — вызов сейчас (this = obj), без скобок — это сама функция (ссылка), при позднем вызове `this` теряется
- `bind` вшивает `this` по ССЫЛКЕ на объект, а не копию значений: меняешь свойство объекта позже — забинженная функция видит новое значение
- Когда собственное свойство объекта совпадает с прототипным — выигрывает собственное (shadowing), поиск по цепочке дальше не идёт

## Notes
- `this` теряется = указывает не туда, а НЕ «свойств нет». Свойства на месте, просто `this` не указывает на их объект
- Методы объекта писать обычной функцией, не arrow (arrow сломает `this`)
- Связь «ссылка, а не копия» (bind и прототип) — основа будущей темы Value vs Reference (M1B)
- `Object.create` + метод на прототипе — это «класс вручную»; в JS 11 то же запишется через `class`
- В React `this` почти уйдёт (arrow + хуки), но механику знать обязательно для собеседований
